# Support

For ordinary defects, use the [GitHub issue tracker](https://github.com/caamer20/tab-leak-guard/issues). Include the extension version, Firefox version, operating system, monitoring scope, what the toolbar reported, and reproducible steps. Do not include page content, form values, cookies, account data, or private URLs. Exported local diagnostics should be reviewed before sharing.

For a potential security or unintended-tab-action issue, follow `SECURITY.md` and do not open a public report containing sensitive details.

The public issue tracker and GitHub private security reporting are configured. A maintainer must monitor both before marketplace publication. This is a release candidate with no guaranteed response time.
