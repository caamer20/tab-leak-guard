# Tab Leak Guard 0.1.1

This safety release keeps leak detection local while making every recovery action user-controlled. Automatic tab reset is temporarily unavailable. The extension now supports private 15-minute manual sessions, selected-site access, clearer evidence and status, safer document/action validation, bounded history with delete-all, and generic aggregate notifications.

The detector remains heuristic because Firefox does not expose exact per-tab memory. A finding means sustained resource-growth behavior was observed; it does not prove a memory leak.

Existing 0.1.0 users must install this signed update manually until a listed AMO update channel is established. This repository artifact is unsigned and is for review/testing only.
