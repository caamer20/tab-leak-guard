Privacy & limitations

What this extension knows

Observed

Live DOM growth, mutation retention, resource activity, visible responsiveness, tab state, and an edited-input state—not the input itself.

Never read

Form values, page text, cookies, request bodies, browsing history, screenshots, or account identifiers.

Not available

Exact per-tab memory, detached-DOM size, pure JavaScript heap usage, GPU memory, and Firefox internal pages.

Findings and receipts stay in Firefox extension storage. Notification text is generic by default so a lock screen does not reveal the site.
