Privacy-first tab recovery

Spot sustained tab growth before it takes over Firefox.

Tab Leak Guard learns a page’s normal behavior, looks for sustained resource-growth patterns, and explains evidence it can observe. It does not measure exact memory.

Recovery is notify-only. Automatic recovery is unavailable while safety validation is in progress.

Setup complete

Pin Tab Leak Guard to the Firefox toolbar to start sessions and review findings quickly.

01

Observe trends

Tracks live DOM retention, resource activity, and responsiveness. It never reads page text or form values.

02

Require evidence

Builds a baseline for about five minutes and looks for sustained growth—not one large page update.

03

Review recovery

Prepares an exact unload or reload action, checks the current page again, and asks for your consent.

Important limitation

Firefox does not expose exact per-tab memory to standard extensions. Tab Leak Guard reports possible retained-DOM growth patterns and clearly marks missing or stale evidence.
